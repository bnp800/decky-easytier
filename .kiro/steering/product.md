# Product Overview

This is a Decky plugin template for Steam Deck. Decky is a plugin loader for Steam Deck that allows developers to create custom plugins that extend the Steam Deck's functionality.

The template provides a starting point for building plugins with:
- Frontend UI components that integrate with Steam Deck's interface
- Python backend for server-side logic and system interactions
- Optional C/C++ backend binaries for performance-critical operations
- Communication bridge between TypeScript frontend and Python backend

Target platform: Steam Deck hardware running SteamOS.

Distribution: Plugins are distributed via the Decky Plugin Store or as zip files.
